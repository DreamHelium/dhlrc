# dhlrc 使用方法

dhlrc（也叫 Minecraft Structure Modifier）可以读取 Minecraft 的 NBT 与区域文件，
显示其中的内容，修改区域的基础数据，并把结果写出。本文只介绍你实际会用到的窗口。

## 主窗口与左侧列表

窗口左侧是程序的页面列表，顺序为：

| 条目 | 作用 |
| --- | --- |
| NBT文件阅读器 | 弹出已打开的 NBT 阅读器列表（按各自读取的文件命名），并可以新建阅读器标签页或新建阅读器窗口。 |
| 管理区域 | 打开已载入内存的区域列表。 |
| 区域阅读器及修改器 | 选择一个区域并打开它的工作区：一个选项卡里包含阅读器，以及该区域的修改器、修改历史和材料列表。 |
| 设置 | 打开设置对话框。 |
| 程序目录 | 显示程序使用的各个目录。 |

所有条目单击即可打开（键盘上按回车也可以）；列表上方的“搜索……”框会随输入过滤列表。
条目会作为选项卡在右侧打开。选项卡可以关闭、拖动排序，双击选项卡标题还能把它拆成
独立窗口（该窗口里的“返回选项卡”按钮可以放回去）。关闭最后一个选项卡会回到
“欢迎！”页面，上面有“快速入门”“程序目录”“NBT阅读器”“添加文件至区域”和“载入示例
投影”五个按钮；文件也可以直接拖到欢迎页上。

## 阅读 NBT 文件

1. 单击“NBT文件阅读器”，或点击欢迎页上的“NBT阅读器”。弹出的列表里是已经打开的
   阅读器；“新建阅读器标签页”和“新建阅读器窗口”可以再开一个（在标签页或独立窗口
   里）。阅读器的标签页或窗口会以它读取的文件命名。
2. 把一个 NBT 文件拖到窗口上。一次拖入多个文件会被拒绝，并提示“多个文件被拖入！”。
3. 文件在后台读取：进度条会前进，读取期间窗口仍可操作；读完后显示 NBT 树。
   无法读取的文件会在窗口上方以错误行显示解码器给出的原因，而不是显示一棵
   残缺的树。

阅读器使用随程序一起提供的 Java NBT 编解码器。缺少它时，窗口会显示
“NBT 编解码器不可用。”。

## 管理区域

“管理区域”选项卡保存当前载入内存的区域。除非你主动保存，否则不会写回文件。

- 用“添加”按钮、欢迎页的“添加文件至区域”，或直接把文件拖到窗口里来添加文件。
  “载入示例投影”会载入随程序附带的投影，不用先找文件就能试用阅读器。文件选择对话框
  是“选择文件”；载入在后台进行。
- 只包含一个区域的文件会直接载入：“选择要载入的区域”这一步只在确实有得选时出现。
- 每一行显示区域的显示名称、灰色的 UUID、“添加于：……”，以及打开阅读器、重命名、
  移除和保存四个按钮。重命名会弹出“输入新名称”，修改的是区域自身的名字。
- 程序正在处理某个区域时（例如保存），该区域会被锁定。锁定的行显示“已锁定！”，
  按钮不可用；工作结束后会自动解锁。锁定的区域不能重命名、移除或选中。已经打开着
  的编辑器也会暂停：输入框被禁用，顶部有一行说明原因，正在填写的内容既不会被拒绝
  也不会丢失。
- 勾选“选择”会出现复选框和第二条工具栏。“全选”可全选或全不选，标签会显示已选
  数量，“移除选中项”和“保存选中项”对所选区域生效；已锁定的区域会被保留并给出警告。
- 保存时先在“选择保存格式”里选择格式。如果该格式能把多个区域写进一个文件，并且你
  选了多个区域，会先问“使用多区域功能？”：选“是”写进一个文件，选“否”每个区域一个
  文件。之后选择文件（“选择文件”）或目录（“选择目录”）。

## 区域阅读器及修改器

1. 单击“区域阅读器及修改器”会弹出已载入区域的列表；也可以直接点区域行上的阅读器
   按钮。列表中已经打开工作区的区域会带勾选标记；点击其中一项会打开该区域的工作区，
   若已经打开则切到那个选项卡，并回到阅读器页。
2. 区域只占一个以它命名的选项卡：阅读器、修改器、修改历史、材料列表和 3D 预览都是
   这个选项卡里的子页，所以打开多个区域时不会每个工具各占一个顶层选项卡。页面顶部会重复区域的
   名称和 UUID。再次请求同一区域会切到已打开的那个选项卡，不会重复打开。它会先下载
   该版本的语言文件。
3. 上方显示区域的基础数据：大小与坐标、DataVersion、版本名、创建与修改时间、作者、
   名称和描述。
4. 在“请输入方块的坐标：”下填写 x、y、z。三者都有效时，“信息为：”会列出方块名称、
   翻译名称、索引、调色板项和属性。语言文件下载完成后，这里以及已经打开的列表会立刻
   刷新，翻译名称无需重新输入坐标就能显示。
5. 阅读器右下角的“工具”按钮打开它的工具：“修改区域”会打开同一选项卡里的“修改器”
   子页，可编辑时间、描述、偏移、作者、基础名字、区域名称和 DataVersion；“展示所有
   实体”和“展示实体NBT”打开 NBT 视图；“列出方块”和“展示方块”打开方块列表与方块视图；
   “3D 预览”会打开同一选项卡里的“3D 预览”子页。“修改属性”对带属性的方块可用。区域被加载或保存任务占用时，
   会写数据的工具（“修改区域”“修改属性”）会变灰。选择“所有使用该调色板项的方块”时
   会列出将被修改的方块；该列表只有在选中这一项时才会去查找（因为查找需要遍历区域里的
   每个方块）。
6. 从阅读器打开的东西都属于它：关闭工作区时，方块列表、方块视图、实体 NBT 视图会
   一起关闭；3D 预览是工作区的子页，也随工作区一起关闭。保持工作区打开不会锁定区域——“已锁定”只表示有加载或保存任务
   正在处理它。
7. 工作区里的子页（阅读器、修改器、修改历史、材料列表、3D 预览）可以拖动标题调换
   位置、用
   关闭按钮关闭，双击标题还能剥离成独立窗口，窗口上的“返回标签页”按钮会把它放回去。
   主窗口里仍然只有一个选项卡代表整个区域。
8. “修改历史”打开同一选项卡里的“修改历史”子页，按时间倒序列出该区域做过的修改：基础
   数据各项、区域自身名字、方块或调色板属性。选中一条后下方显示它的明细：时间以及
   修改前后的值（如“facing: east -> west”）。“撤回选中”撤回一条，“全部撤回”从最新
   的一条开始逐条撤回；区域被后台任务占用时两个按钮都不可用。撤回不了的修改会留在
   列表里，不会悄悄消失。

## 设置

单击“设置”打开分页对话框，页面有“概况”“默认”“游戏”“阅读器”“通知”“3D 预览”
和“管理”。最后一页是已载入模块提供的选项：每个模块是一层折叠，展开后再按“读取/
写入”分节，再展开才是具体选项——选项多的模块不会把下一个挤出页面。每个选项在上面的
“使用已保存的选项”未勾选时是灰色的；数值项只能填模块给出的范围（例如 Sponge 格式
版本是 0–3）。每页底部显示配置文件路径，旁边有打开其
所在目录的按钮。

底部按钮是“恢复默认值”“重新加载”“应用”“确定”和“取消”。“重新加载”会重新读取
配置文件并放弃你的修改；“应用”保存但不关闭对话框。你大概率会用到的设置：

- 应用内存限制和“内存限制单位”：两项分开填写，限制值就按所选单位计数（默认 500 MiB），
  可以带小数，例如 1.5 GiB。以及缓存目录。
- 失败时尝试其它模块：先由扩展名指向的模块读取，失败时再试其它模块。若文件按其名字
  或格式来看存在异常，会在加载完成后提示，而不是直接拒绝。
- 可爱语言包：使用带喵、捏、颜文字和 emoji 的俏皮语言包，而不是普通的翻译。
  它在程序启动时读取，所以勾选后需要重启，整个窗口才会用那种语气说话。
- 多区域显示名称，其“预览……”按钮会显示实时示例。
- 方块名称语言和默认展示选项，控制方块名称的显示。
- 自动下载客户端 jar，3D 预览需要它。

## 程序目录

“程序目录”会打开一个独立窗口（不是选项卡）。它用一棵“名称”“大小”“路径”三列的
树，列出程序使用的三个位置以及每个位置里的文件：

- “程序”——程序所在的文件夹，里面有 `region_module/`、`load_module/` 和 `locale/`。
- “配置”——存放 `config.toml` 的文件夹，所有设置都在这个文件里。
- “缓存”——下载的客户端 jar（`client_jar/`）、资源包，以及从中读出的资源。

双击一行可在文件管理器中打开它；“打开”“刷新”“关闭”三个按钮作用相同，右键单击一行
还有“打开”和“复制路径”。这些目录的实际位置是：

| 内容 | 位置 |
| --- | --- |
| 配置 | `~/.config/dhlrc/config.toml`，或设置了 `$XDG_CONFIG_HOME` 时的 `$XDG_CONFIG_HOME/dhlrc/config.toml`；Windows 上是 `%APPDATA%\dhlrc\config.toml`。 |
| 缓存 | `~/.cache/dhlrc`，或 `$XDG_CACHE_HOME/dhlrc`；Windows 上是 `%LOCALAPPDATA%\dhlrc`；macOS 上是 `~/Library/Caches/dhlrc`。 |
| 程序与模块 | 窗口中名为“程序”的那个文件夹。 |

配置文件是纯文本，文件变化时程序会自动重载。卸载不会删除配置和缓存，所以卸载前后
都应检查这些目录；想彻底清理就自行删除。

## 配置与帮助菜单

- “配置”改变外观：一个配色方案子菜单，以及一个列出系统已安装图标主题的“图标主题”
  子菜单。
- “帮助”里有两项：“帮助”打开帮助窗口（左侧是可过滤的主题列表，有“快速入门”和
  “创建区域”两个主题），“关于”显示版本号以及已载入的区域模块和编解码器模块。
